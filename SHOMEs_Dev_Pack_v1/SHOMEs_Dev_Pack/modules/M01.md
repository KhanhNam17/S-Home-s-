# M01 — Nền tảng UI và catalog

## FE
Tạo PublicLayout, OwnerLayout, AdminLayout; navigation theo /auth/me. Shared Button/Input/Select/Dialog/Toast/Badge/Table/EmptyState/Skeleton, formatter VND/m²/date. Catalog query cache dùng chung.
Bootstrap gọi /auth/csrf rồi /auth/me; loading auth không nháy menu admin/owner. Catalog lỗi hiển thị retry thay vì danh sách option rỗng bị hiểu là không có dữ liệu.
Màn PUB-01 dùng listing query thật cho card; không tự ghi số lượng khách hoặc review giả.

## BE
CatalogModule cung cấp areas, amenities, places; chỉ active area. /places?q normalize không dấu, top10 stable name/id. GET catalog không cần account. Seed code ổn định; UI không dùng label làm key.
Health live/ready và envelope/requestId được hoàn thành tại module nền.

## API / dữ liệu
GET /catalog/areas, /catalog/amenities, /catalog/places, /health/live, /health/ready.
Areas dùng nhóm khu vực, không diễn giải thành danh sách đơn vị hành chính hiện hành. Data: code/name/active; place có id/name/areaCode/lat/lng.

## Luồng và trạng thái
App mount → bootstrap → catalog → render shell; auth lỗi mạng cho retry, không suy ra admin.
Map/API/AI errors không làm header/navigation crash. Mobile có drawer, keyboard và focus đúng.
