# M09 — So sánh tối đa ba phòng

## FE
CompareTray local IDs tối đa3, toast khi vượt; không duplicate. PUB-05 chỉ gọi API khi có2–3.
Một controls assumptions dùng chung; bảng có rent/monthly/deposit/moveIn, area, amenities, vị trí/travel/cập nhật. Đổi assumptions cập nhật toàn bảng.
Giữ thứ tự chọn và row unavailable; guest không login. localStorage chỉ ID, không thông tin liên hệ hay snapshot giá.
Row rented/hidden/draft/capacity incompatible không có CTA gửi lịch.

## BE
POST compare batch load IDs và enforce projection từng row. IDs unique,2..3. Missing/nonpublic→unavailable không lộ title/ảnh, không fail toàn bảng.
Approved rented→rented có thông tin public. Occupants vượt capacity→incompatible_assumptions, vẫn cho đọc public listing nhưng cost null.
CostService cùng M06; TravelProvider cùng M07. Không viết công thức khác trong endpoint này.
Không có bảng saved_comparisons hoặc account guest trong demo.

## API
POST /listings/compare {ids,assumptions,destinationId?}.
Response rows giữ thứ tự; state + listing|null + cost|null + travel|null.
