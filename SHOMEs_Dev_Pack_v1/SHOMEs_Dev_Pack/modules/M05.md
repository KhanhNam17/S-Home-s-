# M05 — Tìm kiếm và danh sách phòng

## FE
PUB-01 entry search, PUB-02 results, PUB-03 map/list dùng một normalized filter object từ URL.
Chọn area, budget rent/total, range, areaM2, amenities, destination/time, assumptions; sort/pagination.
Filter thay đổi debounce300ms reset page; request có abort và query key đầy đủ. Chip hiển thị filter đang áp dụng; clear từng/all.
Card dùng PublicListingSummary: ảnh/tiêu đề/giá/khu vực/diện tích/phí dự kiến/trạng thái cập nhật. CTA detail/compare.
Empty thực sự khác lỗi/SEARCH_TOO_BROAD/travelIncomplete.

## BE
Một SearchService cho public và AI (AI dùng internal call, không gọi HTTP vòng). Chỉ approved+available.
SQL basic filters →candidate cap500 →batch cost/travel →hard computed filter →stable sort →total →page/markers.
Vượt500 candidate sau basic filters:422 SEARCH_TOO_BROAD, không cắt500 rồi nhận là full result.
Fee unknown với total cap bị loại; travel unknown với maxTravel bị loại, metadata giải thích thiếu dữ liệu.
Không lọc/paginate trước khi tính tổng/travel. Query total count cùng thuật toán.
Map markers same filter, cap200 có flag; đang xem page1 vẫn có marker của page khác.

## API
GET /listings và query table ở04. data.items và data.markers, meta.total/page/pageSize/totalPages/mapTruncated/travelIncomplete.
Search response không chứa private fields hoặc owner email.

## Luồng
URL →normalize →fetch →render list/map →change filter →abort old →fetch latest.
Tin vừa rented sau render: card có thể còn snapshot; mở detail refetch trả rented, createViewing vẫn BE chặn.
Sort total giá unknown cuối khi không có cap; sort travel cần destination.
